B端 SaaS 系统 · 从 0 到 1 架构构建

B-Link 智能客悦系统，
全链路数字化新生

这是一个从零开始打造的 SaaS 行业一体化 CRM 系统。我们摒弃了传统的碎片化工具，旨在打造一个底层逻辑统一、跨越营销、销售与售后边界的全新数字化工作台。

01. 项目背景与目标

SaaS 行业长久以来面临着“高客单价获客难、长决策周期转化难、重配置属性交付难”的痛点。市面上的通用系统无法满足业务流转需求，亟需从 0 开始构建一套深度贴合该行业属性的专属闭环系统。我们的目标是：实现全时段自动化获客、无缝化跨部门交接，以及智能化的售后支持体系，以设计赋能业务增长。

02. 角色职责与设计流程

作为本项目的 UI/UX 主设计师，我主导了从业务调研、信息架构搭建到高保真界面落地的全周期体验设计，并在执行中深入应用 HTML 基础与前端协同验收，结合 AI 工具辅助日常工作流提效。

需求拆解与架构构建

对接运营、销售与管理层，梳理多角色业务流，从 0 规划庞大系统的信息架构与 RBAC 权限体系。

交互推演与原型落地

绘制核心业务泳道图，输出高保真界面与关键路径的可交互原型，确保跨部门流转逻辑严密闭环。

组件规范与前端协同

建立具有高复用性的底层 UI 组件库，结合前端开发逻辑走查视觉还原度，保障系统的可扩展性与一致性。

03. 用户与需求调研

新系统构建前，我们深入业务一线，对销售与售后团队的真实工作流进行了全盘梳理。在此次调研中，主要聚焦于两大核心痛点：一是跨部门沟通时存在的严重信息断层；二是高频重复的基础咨询对业务线人力的过度消耗。

04. 全局产品结构树

基于“全知视角与角色赋能”原则，摒弃模块拼凑思路，从底层重新搭建了覆盖“全局驾驶舱、营销运营侧、销售跟进侧、售后服务侧及系统基础能力”的五大核心矩阵架构。

05. 核心交互方案展示

直击业务痛点，推演并重塑了三条最重要的流转链路。

01 夜间自动化获客闭环

设计智能兜底接待流程。当夜间无人工在线时，系统自动下发产品资料并引导留资，随后基于地域或轮询规则在次日自动推送到销售的统一工作台，将无效流失转变为精准商机。

02 销售与售后的标准化交接

在订单流中强植入《结构化交接单》。销售确认成交时，必须录入账号开通数、行业等参数；提交后，数据及客户归属权自动穿透给售后部门生成“待配置任务”，实现跨部门信息 100% 同步流转。

03 AI 赋能的售后知识库

结合智能辅助客服拦截基础问答，并将未知问题沉淀至未命中日志中。客服可一键补录操作流以训练 AI。同时，设计了售后数据监控面板，实时掌握响应时长与客户满意度预警。

06. UI组件与规范体系

为确保系统庞大复杂表单和高密度数据的阅读效率，我从零制定了包含色彩语义、排版栅格、图标库及各类数据录入组件的设计规范，极大提升了开发团队的复用性与界面的高度一致性。

07. 设计成果与商业影响

作为一款从无到有构建的业务系统，B-Link 上线后成功取代了企业过去使用的碎片化工具组合，在效率端交出了亮眼的答卷。

08. 总结与反思

从 0 到 1 构建复杂的 B 端系统是一场对业务深度理解与逻辑归纳能力的双重考验。设计不应仅仅停留在“页面是否美观”，更在于是否解决了角色间的信任与流转效率问题。系统虽然上线，但在异常状态处理与移动端轻量化适配上仍有打磨空间。在未来的迭代中，我将继续深入真实业务场景，沉淀更加成熟的组件规范库。
